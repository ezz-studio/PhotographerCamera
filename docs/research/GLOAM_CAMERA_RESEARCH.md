## 2. 已确认的产品功能（A 类 + 部分 B 类）

1. **胶片 / CCD 预设体系**：以"相机风格 + 胶片色彩配置"组织，而非单一滤镜；预设泛用性高，白天 / 阴天 / 室内 / 夜晚均易出片（B，[搜狐评测](https://m.sohu.com/a/1085901492_413981)）。
2. **日期打印 + 相机边框**：作为胶片真实感的外在标识（A，官方）。
3. **黑柔（black-mist）扩散**：GRD 街头风格内置（A，官方）；与 Halation / Bloom 不同，是"柔化扩散"而非"高光辉光"。
4. **1x 主摄的旁轴式取景框**：可看到画框外内容再决定快门（B，[搜狐](https://m.sohu.com/a/1085901492_413981)）——产品交互灵感，非成像管线。
5. **"数字底片"与拍后重调**：拍摄后保留一份类数字底片数据，可重选同机内其他预设、调整影调与白平衡，确认后一键清除（B，[腾讯新闻](https://news.qq.com/rain/a/20261010A05H7T00) / [搜狐](https://m.sohu.com/a/1085901492_413981)）。**这是非破坏性重调（non-destructive re-grade）的产品化体现。**
6. **处理有等待时间、不适合高速连拍**：质量优先于速度的架构取舍（B，多篇评测）。

## 3. 可观察的视觉 / 产品特征（B 类，来自评测与样片描述）

- **颗粒是核心卖点**：大小与强度"恰到好处，基本直出可用"（[搜狐](https://m.sohu.com/a/1085901492_413981)）；[爱范儿/凤凰网](https://tech.ifeng.com/c/8wWHI1j7jZt)描述为"仿胶片般的细腻银盐颗粒，色调带着胶片独有的温润旧意"。→ **Grain 是 hero feature，且与分辨率 / 画幅相关（长焦小底"软 + 粗 + 细颗粒"反而成风格）。**
- **色彩有风格但不夸张**：有明确色彩倾向，但不过度（B，[搜狐](https://m.sohu.com/a/1085901492_413981)）。
- **不追求绝对锐利**：胶片照片本就不追求锐利；处理后"稍微软一些、粗糙一些 + 细腻颗粒"成为画面的一部分（B，[腾讯新闻](https://news.qq.com/rain/a/20261010A05H7T00)）。→ 对锐化 / 颗粒平衡有直接启示。
- **CCD 取向**：浓郁油画色 + 柔和影调（CCD12）；即经典 CCD 便携机的色彩与软调。

## 4. 基于样片 / 评测的分析（B 类）

- 评测原文："拍摄时，Gloam 会读取 iPhone 的 **RAW 数据**，完成**色彩映射、影调调整、颗粒处理**，再输出最终的 JPG。"（[搜狐](https://m.sohu.com/a/1085901492_413981)）。这是媒体对处理逻辑的技术性描述（B，非开发者声明），但与"胶片模拟预设"的产品定位一致：**RAW → 色彩映射 → 影调 → 颗粒 → JPG** 的处理链，而非在已有 JPEG 上叠加滤镜。
- "数字底片"机制说明其渲染链是**参数化、可重算**的（保留 RAW / 中间参数，事后换预设 / 调影调 / 调白平衡），这与**快照 + 离线重渲染**架构一致。
- 长焦（4x）样张观感：软、粗、带细颗粒 → 说明 Gloam 的颗粒与"画幅 / 传感器尺寸"感知相关，且接受适度软化为风格一部分。

## 5. 合理推断（C 类）

- **处理链推断**：色彩映射（Color Matrix / LUT）+ 影调调整（Tone Curve / Highlight-Shadow / Film Curve）+ 颗粒（Grain）的三段式，与 PhotographerCamera 现有管线高度同构。具体算法未知，仅作架构层类比。
- **胶片 / CCD 预设实现**：大概率采用 3D LUT + 色彩矩阵 + 影调曲线 + 颗粒叠加的组合（业界胶片模拟通行做法）。**不确认 Gloam 具体是否用 LUT、何种采样。**
- **CCD 风格**对应低分辨率、特定色彩科学、偏软、特征性噪声取向——与"不追求锐利 + 细颗粒"的观感互证。
- **黑柔（GRD）**是一种扩散柔化（类似黑柔滤镜的低对比柔光），区别于高光辉光（Halation / Bloom）。

- 色彩映射是否依赖设备色彩校准 / 场景识别。

## 7. 对 PhotographerCamera 有价值的借鉴方向

| Gloam 特征（证据级） | 对 PhotographerCamera 的借鉴 | 当前对齐情况 |
|---|---|---|
| RAW → 色彩映射 → 影调 → 颗粒 → JPG（B） | 验证"非 RAW 为主、RAW 可选"与 Profile 参数化管线方向正确 | ✅ 已有：RGBA_F16 主链 + Profile 渲染链（Phase C/E） |
| 数字底片 / 拍后重调预设 + 影调 + 白平衡（B） | 非破坏性快照 + 离线重渲染 | ✅ 已有：`CaptureProfileSnapshot`（Phase B，快门冻结 Profile 快照，预览/相册重渲染跟随活参数） |
| 颗粒作为 hero feature，按画幅 / 分辨率感知（B） | 颗粒需按分辨率 / 画幅尺度一致、亮暗部差异合理 | ⚠️ 已在管线中存在（Grain pass），需按 Phase 5.3 持续校验"预览 vs 成片颗粒尺度一致" |
| 色彩有风格但不夸张、跨光照泛用（B） | LUT / 风格母版优先，避免过饱和 | ✅ Profile LUT 体系 + 中性原生档 |
| 黑柔扩散（A，GRD） | 与 Halation / Bloom 区分；可作为独立柔光层候选 | ⚠️ 现有 Halation/Bloom 为辉光型，黑柔=扩散柔化，属不同语义；若引入需单列 |
| 接受软化为风格一部分（B） | 锐化强度克制，避免塑料感 | ⚠️ Sharpen pass 需按 Phase 5.5 校验不放大噪声、不产生光晕 |
| 旁轴取景框（B） | 产品交互灵感（非管线） | ➖ 不在当前相机引擎范围 |
| 日期打印 + 边框（A） | 胶片真实感外在标识（产品功能） | ➖ 可后续作为导出层 |

**结论**：Gloam 的公开信息**验证而非颠覆**了 PhotographerCamera 已落地的架构方向（RAW 参数化管线、Profile 预设、快照可重算、颗粒优先）。其核心可借鉴增量集中在 **(a) 颗粒质量与跨分辨率一致性**、**(b) 黑柔类扩散层与辉光层的语义区分**、**(c) 非破坏性"数字底片"交互的产品化**（我们已有快照能力，可向前端暴露"拍后重选预设"）。这些均属 P2/P3 级打磨，不要求重写架构。
